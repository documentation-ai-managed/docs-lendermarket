# Full statistics

The full feed contains headline KPIs, monthly time series going back to September 2018, and a portfolio health breakdown. Use it for charts and detailed statistics pages.

```
GET https://lib.lendermarket.com/statistics/platform-statistics-{YYYYMMDD}.json
```

No authentication is required. See [Platform Statistics](/api/statistics/introduction) for the date fallback pattern and general data conventions.

### Response fields

<ResponseField name="generated_at" field-type="string" required="true">
  Timestamp when the file was generated, ISO 8601, UTC
</ResponseField>

<ResponseField name="headline_kpis" field-type="object" required="true">
  <Expandable title="Object Properties" default-open="false">
    <ResponseField name="total_invested_all_time" field-type="number" required="true">
      Total amount invested through the platform since launch, in EUR
    </ResponseField>

    <ResponseField name="total_interest_paid_all_time" field-type="number" required="true">
      Total interest paid to investors since launch, in EUR
    </ResponseField>

    <ResponseField name="interest_paid_ytd" field-type="number" required="true">
      Interest paid to investors in the current calendar year, in EUR
    </ResponseField>

    <ResponseField name="active_portfolio" field-type="number" required="true">
      Outstanding principal of the active loan portfolio, in EUR
    </ResponseField>

    <ResponseField name="registered_investors" field-type="integer" required="true">
      Total number of registered investors
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="platform_overview" field-type="object" required="true">
  Monthly time series. Each series is an object with a `description` string and a `series` array. Series entries are ordered chronologically, and the latest entry is a month-to-date value.

  <Expandable title="Object Properties" default-open="false">
    <ResponseField name="new_loans_listed" field-type="object" required="true">
      Loans listed per month. Series entries contain `date` (`YYYY-MM`), `value` (amount listed in EUR) and `count` (number of loans listed).
    </ResponseField>

    <ResponseField name="cumulative_loans_listed" field-type="object" required="true">
      Running total of loans listed since launch. Series entries contain `date`, `value` (cumulative amount in EUR) and `count` (cumulative number of loans).
    </ResponseField>

    <ResponseField name="cumulative_investment" field-type="object" required="true">
      Running total of investments made since launch. Series entries contain `date` and `value` (cumulative amount in EUR).
    </ResponseField>

    <ResponseField name="monthly_investment" field-type="object" required="true">
      Amount invested per month. Series entries contain `date` and `value` (amount in EUR).
    </ResponseField>

    <ResponseField name="active_portfolio_over_time" field-type="object" required="true">
      Historical size of the active loan portfolio, in EUR. Series entries contain `date` and `value`. This series starts in April 2024.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="portfolio_health" field-type="object" required="true">
  <Expandable title="Object Properties" default-open="false">
    <ResponseField name="outstanding_principal" field-type="object" required="true">
      Contains `total`, the outstanding principal of the active portfolio in EUR, and `by_status`, an array splitting it by payment status. Each `by_status` entry has a `label` and a `percentage` of the outstanding principal. Labels returned are `current`, `late_1_15_days`, `late_16_30_days`, `late_31_60_days` and `pending_payments`. Percentages add up to approximately 100, subject to rounding.
    </ResponseField>

    <ResponseField name="default_rate_pct" field-type="number" required="true">
      Share of the outstanding portfolio in default, in per cent
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="investor_base" field-type="object" required="true">
  <Expandable title="Object Properties" default-open="false">
    <ResponseField name="registered_investors" field-type="integer" required="true">
      Total number of registered investors
    </ResponseField>
  </Expandable>
</ResponseField>
